# SKILL_01 – Website-Analyse

## Ziel
Aus Unterseite (Produkt/Leistung) und Hauptseite (Unternehmen) einen Steckbrief erstellen, der alle Fakten für Kampagne, Keywords, RSA und Assets enthält.

## Vorgehen
1. Unterseite lesen: Title, Meta-Description, H1, H2/H3, Fließtext, Aufzählungen, Preise, CTAs, FAQ.
2. Hauptseite lesen: Navigation (Hauptmenü), Footer-Links, Claims, Trust-Elemente (Bewertungen, Siegel, Jahre am Markt, Kundenzahl), Kontakt, Standorte.
3. Echte Unterseiten-URLs für Sitelinks sammeln (nur Links, die auf derselben Domain wirklich existieren): z. B. Kontakt, Über uns, Leistungen, Preise, Referenzen, FAQ, Termin/Angebot.
4. Ansprache bestimmen: Spricht die Website mit Du oder Sie?

## Steckbrief (genau dieses Format ausgeben)
| Feld | Inhalt |
|---|---|
| Marke / Unternehmen | |
| Domain | |
| Thema der Unterseite (2–4 Wörter) | wird Name der Anzeigengruppe |
| Angebot in einem Satz | |
| Zielgruppe | |
| Hauptproblem der Zielgruppe | |
| Top-Nutzen (max. 5) | |
| USPs / Belege (max. 5) | nur belegbar |
| Preise / Konditionen | nur wenn auf der Seite |
| Region / Einsatzgebiet | |
| Gewünschte Aktion (CTA) | z. B. Anfrage, Kauf, Termin |
| Ansprache | Du / Sie |
| Sitelink-Kandidaten | Linktext → URL |
| Sensibles Thema? | ja/nein + Grund |
| Quelle der Inhalte | je Seite: Live-Seite / Suchtreffer / Text vom Nutzer |

## Regeln
- Nur Fakten, die wörtlich oder sinngemäß auf den Seiten stehen. Kennzeichne Annahmen mit „(Annahme)“.
- Wenn Unterseite und Hauptseite sich widersprechen, gilt die Unterseite.
- Kann eine Seite nicht geladen werden: Ablauf im Abschnitt „Wenn eine Seite nicht lesbar ist“. Keine Vermutungen über den Inhalt.
- Unklare Marke: nimm den Namen aus Logo-Alt-Text, Impressum oder Title-Tag.

## Wenn eine Seite nicht lesbar ist
Hintergrund: Die Websuche liest Seiten über den Suchindex (Bing), nicht direkt. Neue oder nur über Anzeigen verlinkte Landingpages fehlen dort oft, obwohl sie im Browser funktionieren.

Gehe in dieser Reihenfolge vor und hör auf, sobald der Inhalt vorliegt:
1. Gezielt suchen: Domain plus Wörter aus dem URL-Pfad (Bindestriche als Leerzeichen), z. B. für muster-gmbh.de/leistungen/waermepumpe-einbau-muenchen: „muster gmbh waermepumpe einbau muenchen“. Danach mit „site:domain.de“ und den wichtigsten Pfadwörtern. Nur einen Treffer mit exakt derselben URL (oder derselben URL ohne Parameter) verwenden.
2. Hauptseite getrennt lesen. Ist sie lesbar, reicht sie für die Konto-Assets (SKILL_05). Für Kampagne, Keywords und RSA reicht sie NICHT – diese brauchen den Inhalt der Unterseite.
3. Ist die Unterseite danach nicht vollständig lesbar, frag in EINER kurzen Nachricht nach dem Inhalt und stoppe:
   „Die Seite [URL] kann ich nicht lesen (sie ist vermutlich noch nicht im Suchindex). Bitte kopiere mir den Seitentext hier in den Chat:
   – Wichtig sind Überschriften, Einleitung, Leistungen/Vorteile, Preise, Ablauf und Handlungsaufforderung. Menü, Footer, Cookie-Hinweise und Bewertungen kannst du weglassen.
   – Pro Nachricht passen max. 2.000 Zeichen. Bei längeren Seiten den Text in mehreren Nachrichten schicken und am Ende „fertig“ schreiben.“
   Ist die Hauptseite lesbar, ergänze: „Die Startseite konnte ich lesen; die Konto-Assets kann ich schon erstellen, wenn du möchtest.“
4. Mehrteilige Eingabe: Antworte auf jeden Teil nur mit „Teil [n] erhalten. Nächster Teil oder ‚fertig‘.“ – keine Analyse, keine Zwischenergebnisse. Erst nach „fertig“ alle Teile zusammen auswerten. Schickt der Nutzer nur einen Teil ohne „fertig“ und der Text wirkt vollständig, frag kurz: „Ist das alles? Dann schreib ‚fertig‘.“
5. Eingefügten Text genauso auswerten wie eine Live-Seite. Die Final URL bleibt die vom Nutzer genannte URL. Fehlen danach Pflichtangaben für den Steckbrief (Angebot, Nutzen, CTA), frag gezielt nur danach.

Regeln dazu:
- Suchtreffer-Ausschnitte (Snippets) allein sind keine ausreichende Grundlage für Steckbrief, Keywords oder Anzeigentexte.
- Nie den Inhalt aus URL-Wörtern, Domainname oder anderen Seiten der Website erraten.
- Gilt auch für „ohne Rückfrage“ / „direkt“: Fehlt der Seiteninhalt, ist die Rückfrage aus Schritt 3 trotzdem Pflicht.
- In der Zeile „Quelle der Inhalte“ des Steckbriefs angeben, woher die Inhalte stammen.
