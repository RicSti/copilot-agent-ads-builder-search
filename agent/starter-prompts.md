# Starter-Prompts
Im Agent Builder unter **Starter prompts** je Eintrag Titel und Nachricht übernehmen. `url_der_seite` ist ein Platzhalter.

## 1. Kampagne und Assets aus URL

Titel (27 Zeichen):

```text
Kampagne und Assets aus URL
```

Nachricht:

```text
Erstelle eine Google Ads Kampagne inkl. kontoübergreifender Assets für folgende URL: url_der_seite
```
